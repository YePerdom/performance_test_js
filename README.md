# Performance test js

This is a **Single Page Aplicatio (SPA)** created with **JavaScript**, **HTML** and **CSS**, where you can manage events, design to events organizer can manage series of events subject to availability of venues and attendees.

## Funcionalities

* Authentication system.
* Session persistence.
* Data consistency.
* User interface.

## How to run
 - install dependencies
 ```bash
npm install
```
- Run the development server
```bash
npm run dev
```
